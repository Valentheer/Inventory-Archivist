# Changelog

## 0.1.2j-alpha — Community testing package
- Fresh installations default to custom bag positioning enabled, locked, and position controls always visible.
- Existing user preferences are preserved.
- Previous alpha work stabilized combined/separate bag positioning, keyring and reagent bag handling, saved coordinates, and reset behavior.
- Refined native-style lock control and title-bar spacing.
- Public-package housekeeping: removed development-note files, refreshed version message and metadata, added documentation.

### Known minor issue
- A natively stacked bag may briefly follow another bag during drag before snapping back to its saved location.
